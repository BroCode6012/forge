🟨 Lightning Vision Accounts

          
        

        

          

            Builds rotate through the configured Lightning GPU accounts; when one reaches its local hour budget or Lightning rejects it for insufficient credit, the app switches to the next and falls back to Bedrock if none are usable. When an account's credit refreshes, click Reset to put it back in play.
            
New accounts default to T4. Lightning may still enforce account-specific billing, credit, or payment checks before GPU compute can start. Confirm each teamspace's spending limit before enabling builds.

          

          

            
            
          

          


          

            
➕ Add an account

            

              From lightning.ai → Settings → Keys → Programmatic login copy your User ID + API Key. The Studio fields come from your Studio URL: lightning.ai/<user>/<teamspace>/studios/<studio>. (The Studio must already have serve-vision.sh + vLLM set up.)
